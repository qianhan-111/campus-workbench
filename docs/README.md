# 使用说明

这里是各课程的课件归档目录（docs/<课程名>/）。

## 怎么用
- 把课件 PPT / PDF / 讲义拖进对应课程的文件夹，然后在 WorkBuddy 对话里说一句：
  「把这份课件放进 <课程名>」即可完成登记，课程资料库页面会自动显示。
- 资料库页面的「AI 陪读问答」会读取本目录的文件来回答你的问题。

## 目录约定
- docs/操作系统/      操作系统（李静）
- docs/数据结构/      数据结构（王强）
- docs/高等数学A/     高等数学A（张伟）
- docs/机器学习导论/   机器学习导论（赵敏）

当前为演示用的 Markdown 讲义样例，实际使用可替换为 PPT/PDF。
