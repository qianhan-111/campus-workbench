# 第2周 · CPU 调度算法

## 1. 调度目标
- CPU 利用率、吞吐量、周转时间、等待时间、响应时间
- 冲突：响应时间 vs 吞吐量

## 2. 经典算法
- FCFS 先来先服务：简单，但长任务会"堵车"（护航效应）
- SJF 最短作业优先：平均等待时间最短，但需要预知运行时间，可能饿死长任务
- 优先级调度：可能饿死低优先级 → 用"老化 Aging"解决
- 时间片轮转 RR：固定时间片循环，响应好，时间片大小是关键参数
- 多级反馈队列 MLFQ：多个队列 + 动态优先级，兼顾交互与吞吐，现代 OS 主流

- 对比 RR 与 MLFQ 各自适合的场景
- 阅读教材 5.3 节，思考"为什么实际系统不用纯 SJF"
