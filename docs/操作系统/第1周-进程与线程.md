# 第1周 · 进程与线程

## 1. 什么是进程
- 进程 = 正在执行的程序实例（程序 + 运行状态）
- PCB（进程控制块）：描述进程的所有信息，是进程的"身份证"
- 进程四要素：代码、数据、堆栈、PCB

## 2. 进程三态模型
- 就绪（Ready）→ 运行（Running）→ 阻塞（Blocked）
- 就绪队列 / 等待队列；CPU 调度器从就绪队列选进程

## 3. 上下文切换
- 切换开销：保存当前进程寄存器与 PCB，加载下一个进程
- 切换频率与开销的权衡（时间片越短越"公平"但切换越频繁）

## 4. 进程 vs 线程
- 线程是 CPU 调度的最小单位，进程是资源分配的最小单位
- 同一进程内线程共享地址空间；进程间地址空间隔离
