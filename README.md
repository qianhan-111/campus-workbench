# 今天 · 校园课程工作台

> 打开就知道「今天上什么课、要交什么」；点进任何一门课，就是这门课的资料库和 AI 陪读。

在线页面（只读）：<https://workbuddy.link/p/2vH9bvYE2YTXvnuPojtaEH>

## 功能

- **今日**：今日课程时间轴 + 最近 DDL 队列 + 一句话录入入口
- **周课表**：7 列周视图、单双周与周次范围过滤、页面内直接编辑课程
- **DDL 看板**：紧急 / 临近 / 稍后三档看板，支持完成、撤销、顺延、编辑与删除
- **课程资料库**：课件库 + 富文本笔记 + AI 陪读问答，以课程为入口聚合
- **笔记库**：按课程分组展示笔记与问答历史，附每周复盘

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 单页应用入口（今日 / 周课表 / DDL / 课程页 / 笔记库五个视图） |
| `assets/app.js` | 视图渲染与业务逻辑 |
| `assets/db.js` | 数据读写层 |
| `assets/common.js` | 通用工具函数 |
| `data/*.json` | 演示数据（课表、DDL、笔记、问答、课件清单） |
| `docs/<课程名>/` | 课程课件归档目录 |
| `reports/` | 周复盘记录 |
| `PRD.md` | 产品需求文档（含 V3–V5 全部变更记录） |
